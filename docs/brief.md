# brief — правила хакатона и матрица критериев

Сохраняет текст правил и проверяет, что каждый критерий в `brief.json` действительно взят из них.
Сам сервис правила не «понимает»: критерии по тексту заполняет Claude Code (или человек), а `brief validate`
не даёт вписать то, чего в правилах нет.

## Команды

| Команда | Что делает |
|---|---|
| `brief extract --file rules.md` | сохраняет текст → `.repokit/brief.source.txt`, создаёт заготовку `brief.json`, показывает строки-подсказки |
| `brief extract --text "…"` | то же из текста |
| `brief extract --url https://…` | то же со страницы. Единственная команда сервиса, которая обращается к сети, и только по этому флагу |
| `brief init --default` | правил нет — берётся типовой набор из пяти критериев с пометкой `isDefaultProfile: true` |
| `brief validate` | схема, цитаты, полнота матрицы; код 1 при проблемах |
| `brief matrix` | таблица «критерий → раздел README → чем подтверждается» |

HTML переводится в простой текст. PDF не поддерживается: сохраните правила как текст.

## brief.json

Схема: [schemas/brief.schema.json](../schemas/brief.schema.json).

```json
{
  "schemaVersion": 1,
  "source": { "kind": "file", "ref": "rules.md", "sha256": "…" },
  "isDefaultProfile": false,
  "criteria": [
    { "id": "quality", "title": "Качество реализации", "weight": 0.6, "quote": "Качество реализации — 60%" }
  ],
  "submission": [
    { "id": "video", "title": "Видео", "required": true, "constraint": "до 3 минут", "quote": "обязательно приложить видео до 3 минут" }
  ],
  "deadlines": [],
  "restrictions": [],
  "matrix": [
    { "criterionId": "quality", "evidenceKinds": ["feature", "tests"], "readmeSlot": "features" }
  ]
}
```

## Что проверяет validate

- у каждого критерия, требования, срока и ограничения есть `quote`, и эта цитата находится в тексте правил
  (регистр, пробелы, вид кавычек и тире не учитываются);
- каждый критерий покрыт строкой матрицы, а матрица не ссылается на несуществующие критерии;
- идентификаторы критериев не повторяются;
- сумма весов равна 1 (иначе предупреждение).

Для профиля по умолчанию цитаты не требуются, но и в `validate`, и в README остаётся пометка,
что критерии — допущение, а не правила хакатона.

## Как матрица используется дальше

- `readme` строит раздел «Для жюри»: критерий, вес и ссылки на подтверждения.
- В `claims.json` утверждению можно указать `criteria: ["quality"]` — тогда оно появится в строке этого критерия.
- Ссылка на раздел README ставится только если этот раздел реально есть в выбранном пресете и заполнен.
