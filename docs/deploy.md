# deploy — деплой на бесплатные площадки

Подбирает площадку под тип проекта, готовит конфигурацию, запускает деплой **через ваш собственный CLI** и проверяет,
что сайт отвечает. Сам repokit нигде не логинится, аккаунтов не создаёт и секретов не читает.

## Команды

| Команда | Что делает | Меняет ли что-то |
|---|---|---|
| `deploy providers` | список площадок и ограничения их бесплатных тарифов | нет |
| `deploy detect` | какая площадка подходит проекту и почему | нет |
| `deploy plan [--provider id]` | какие файлы появятся, какие команды выполнятся, что останется вам | только `.repokit/deploy.plan.json` |
| `deploy apply [--provider id] [--dry-run] [--force]` | записывает файлы конфигурации в репозиторий | да; `--dry-run` показывает содержимое |
| `deploy run [--provider id] --confirm` | запускает деплой через ваш CLI | публикует проект; без `--confirm` — код 3 |
| `deploy check --url <адрес> [--path /health] [--timeout 90]` | ждёт ответа сайта и запоминает адрес | `.repokit/deploy.json`; обращается к сети |

## Таблица решений

| Проект | Рекомендуется | Запасные |
|---|---|---|
| Статический сайт | GitHub Pages | Cloudflare Pages, Netlify |
| Python-сервер (FastAPI, Flask) | Render | Fly.io, Hugging Face Spaces (Docker) |
| Node-сервер (Express, Fastify) | Render | Fly.io, Vercel (потребует переделки под функции) |
| Next.js | Vercel | Netlify, Render |
| Streamlit, Gradio | Hugging Face Spaces | Streamlit Community Cloud |
| Проект с Dockerfile | Fly.io | Render |

Для CLI-утилит и библиотек площадка не предлагается. Провайдера всегда можно выбрать вручную — тогда repokit предупредит,
если он не подходит (например, сервер на GitHub Pages).

## Что генерируется

| Площадка | Файлы | Как запускается |
|---|---|---|
| GitHub Pages | `.github/workflows/pages.yml` | пушем; `deploy run` включает Pages и запускает workflow через `gh` |
| Cloudflare Pages | — | `wrangler pages deploy` |
| Netlify | `netlify.toml` для статики | `netlify deploy --prod` |
| Vercel | — | `vercel deploy --prod --yes` |
| Render | `render.yaml` | вручную: New → Blueprint в панели Render |
| Fly.io | `fly.toml`, при отсутствии — `Dockerfile` | `fly deploy`; приложение первый раз создаёте вы |
| Hugging Face Spaces | при необходимости `Dockerfile` | вручную: создать Space и запушить в него |
| Streamlit Community Cloud | — | вручную: подключить репозиторий на share.streamlit.io |

Команда запуска приспосабливается к хостингу: `uvicorn app.main:app` превращается в
`uvicorn app.main:app --host 0.0.0.0 --port $PORT`. Если Node-сервер не читает `process.env.PORT`, будет предупреждение.

Существующий файл с другим содержимым не перезаписывается без `--force`.
Файлы уровня репозитория (workflow, `render.yaml`) пишутся в корень git, даже если проект лежит в подпапке.

## Вход и секреты

- Перед запуском `deploy run` проверяет, вошли ли вы в CLI площадки (`gh auth status`, `vercel whoami` и т. п.).
  Если CLI нет или вы не вошли — код 3 и точная команда, которую нужно выполнить **вам**.
- Из кода собираются только **имена** переменных окружения (`process.env.X`, `os.environ["X"]`, `os.getenv("X")`).
  План перечисляет их и просит задать значения в настройках площадки. Файлы `.env` не читаются, значения нигде не сохраняются.

## Проверка адреса

```bash
node packages/cli/dist/bin.js deploy check --url https://example.onrender.com --path /health
```

Запрашивает адрес каждые 5 секунд, пока не получит успешный ответ или не истечёт время (по умолчанию 90 секунд — запас на холодный старт).
Результат записывается в `.repokit/deploy.json`. Если ответ пришёл не с первой попытки или шёл дольше 5 секунд, это помечается как холодный старт.

Что это даёт дальше:

- `readme` ставит ссылку на работающую версию в раздел «Демо» — только если последняя проверка была успешной;
  для засыпающих площадок рядом честно пишется, что первое открытие может занять до минуты;
- `verify --online` проверяет этот адрес;
- `run` перестаёт напоминать о деплое.

## Ограничения бесплатных тарифов

`deploy providers` и `deploy plan` перечисляют их для каждой площадки: засыпание при простое (Render, Fly.io, Spaces, Streamlit),
холодный старт, требование публичного репозитория (Pages), банковская карта (Fly.io). Условия площадок меняются —
перед показом жюри сверьтесь с их сайтами.

## Что проверено, а что нет

Генерация конфигурации, таблица решений, проверка входа, разбор вывода CLI и проверка адреса покрыты тестами;
запуск деплоя тестируется с подставным исполнителем команд. **Настоящий деплой ни на одну площадку в рамках разработки
не выполнялся**: для этого нужен ваш вход в сервисы.
