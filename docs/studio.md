# studio — монтаж записи

Берёт запись из `capture` и собирает оформленный ролик: фон, окно-рамка, тень, авто-зум по кликам и вводу,
сглаженный курсор с отметкой клика. Содержимое окна — исходная запись без изменений; всё остальное — оформление вокруг неё.

## Что нужно

- Google Chrome или Edge (либо путь в `REPOKIT_BROWSER`) — в нём выполняется покадровый рендер.
- `ffmpeg` и `ffprobe` в `PATH`.
- Рендер выполняет [Remotion](https://www.remotion.dev). Его лицензия не open source: бесплатно для частных лиц,
  некоммерческих организаций и компаний до 3 сотрудников; остальным нужна платная лицензия. См. [ATTRIBUTION.md](../ATTRIBUTION.md).

## Команды

```bash
node packages/cli/dist/bin.js studio styles
```

```bash
node packages/cli/dist/bin.js studio render --repo examples/web-app --out docs/media/hero.mp4 --gif --webp
```

| Флаг `render` | Значение |
|---|---|
| `--out <file.mp4>` | итоговый файл; рядом создаются постер `.png` и, по флагам, `.gif` и `.webp` |
| `--capture <run>` | какая запись: идентификатор или `latest` (по умолчанию) |
| `--timeline <file>` | готовый `timeline.json` вместо автоматического |
| `--style light\|dark\|glass` | оформление |
| `--width`, `--height`, `--fps` | размер и частота кадра, по умолчанию 1280×720, 30 |
| `--no-zoom`, `--zoom-scale <n>` | выключить авто-зум или задать кратность (по умолчанию 1.8) |
| `--title <text>` | заголовок над окном |
| `--gif`, `--webp` | дополнительные форматы |
| `--gif-budget-mb <n>` | предел размера GIF, по умолчанию 8 |
| `--dry-run` | показать план и таймлайн, рендер не выполнять |

Использованный таймлайн сохраняется в `.repokit/timeline.json` — его можно отредактировать и передать через `--timeline`.

## Таймлайн

Схема: [schemas/timeline.schema.json](../schemas/timeline.schema.json).

```json
{
  "schemaVersion": 1,
  "output": { "width": 1280, "height": 720, "fps": 30 },
  "style": "light",
  "scenes": [
    {
      "source": ".repokit/capture/20261001-172142/video.mp4",
      "events": ".repokit/capture/20261001-172142/events.json",
      "in": 0, "out": 12.5, "speed": 1,
      "zoom": { "mode": "auto", "scale": 1.8 },
      "cursor": true,
      "title": "Taskboard"
    }
  ]
}
```

Несколько сцен идут подряд. `in`/`out` обрезают фрагмент, `speed` ускоряет или замедляет его.

## Авто-зум

Строится из лога событий ([packages/studio/src/camera.ts](../packages/studio/src/camera.ts)):

- камера приближается к месту клика, ввода или наведения за полсекунды до события и держится ещё 1,3 секунды;
- во время ввода текста зум сохраняется на всё время набора;
- события, идущие чаще чем раз в 1,6 секунды, объединяются в один план: камера не отъезжает, а сдвигается, причём только
  если следующее действие вышло из центральной зоны кадра;
- на время скролла и перехода между страницами камера возвращается к общему плану;
- приближенный кадр никогда не выходит за границы записи.

## GIF в пределах бюджета

GIF кодируется фильтрами палитры `ffmpeg`. Если файл больше бюджета, настройки понижаются по ступеням
(ширина 960 → 400, частота 15 → 8, цветов 256 → 48), пока файл не уложится. Если не уложился и на последней ступени —
команда завершается с кодом 1 и советом сократить ролик.

## Происхождение

Каждый результат записывается в `.repokit/media.manifest.json` с полем `derivedFrom` — хэшами исходных записей и таймлайна.
Если источник сцены не записан через `capture`, рендер выполнится, но выдаст предупреждение «происхождение неизвестно».

## Ограничения

- Рендер 14-секундного ролика 1280×720 занимает около двух минут на обычном ноутбуке.
- Между сценами нет переходов — только прямая склейка.
- Шрифт заголовка берётся системный, поэтому на разных ОС он может немного отличаться.
- Автоматического вырезания пауз нет: используйте `in`/`out` и `speed`.
- 3D-пресеты появятся в вехе M3.
