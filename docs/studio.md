# studio — монтаж записи

Берёт запись из `capture` и собирает оформленный ролик: фон, окно-рамка, тень, авто-зум по кликам и вводу,
сглаженный курсор с отметкой клика. Содержимое окна — исходная запись без изменений; всё остальное — оформление вокруг неё.

## Что нужно

- Google Chrome или Edge (либо путь в `REPOKIT_BROWSER`) — в нём выполняется покадровый рендер.
- `ffmpeg` и `ffprobe` в `PATH`.
- Рендер выполняет [Remotion](https://www.remotion.dev). Его лицензия не open source: бесплатно для частных лиц,
  некоммерческих организаций и компаний до 3 сотрудников; остальным нужна платная лицензия. См. [ATTRIBUTION.md](../ATTRIBUTION.md).

## Команды

```bash
node packages/cli/dist/bin.js studio styles
```

```bash
node packages/cli/dist/bin.js studio render --repo examples/web-app --out docs/media/hero.mp4 --gif --webp
```

| Флаг `render` | Значение |
|---|---|
| `--out <file.mp4>` | итоговый файл; рядом создаются постер `.png` и, по флагам, `.gif` и `.webp` |
| `--capture <run>` | какая запись: идентификатор или `latest` (по умолчанию) |
| `--timeline <file>` | готовый `timeline.json` вместо автоматического |
| `--style light\|dark\|glass` | оформление |
| `--width`, `--height`, `--fps` | размер и частота кадра, по умолчанию 1280×720, 30 |
| `--no-zoom`, `--zoom-scale <n>` | выключить авто-зум или задать кратность (по умолчанию 1.8) |
| `--title <text>` | заголовок над окном |
| `--gif`, `--webp`, `--webm` | дополнительные форматы; WebM — со звуком, если он есть |
| `--click-sounds`, `--music <файл>`, `--music-volume <n>` | звук: щелчки на клики записи и ваша музыка; см. [scenes.md](scenes.md#звук) |
| `--gif-budget-mb <n>` | предел размера GIF, по умолчанию 8 |
| `--dry-run` | показать план и таймлайн, рендер не выполнять |

Использованный таймлайн сохраняется в `.repokit/timeline.json` — его можно отредактировать и передать через `--timeline`.

## Таймлайн

Схема: [schemas/timeline.schema.json](../schemas/timeline.schema.json).

```json
{
  "schemaVersion": 1,
  "output": { "width": 1280, "height": 720, "fps": 30 },
  "style": "light",
  "scenes": [
    {
      "source": ".repokit/capture/20261001-172142/video.mp4",
      "events": ".repokit/capture/20261001-172142/events.json",
      "in": 0, "out": 12.5, "speed": 1,
      "zoom": { "mode": "auto", "scale": 1.8 },
      "cursor": true,
      "title": "Taskboard"
    }
  ]
}
```

Несколько сцен идут подряд. `in`/`out` обрезают фрагмент, `speed` ускоряет или замедляет его.

## Авто-зум

Строится из лога событий ([packages/studio/src/camera.ts](../packages/studio/src/camera.ts)):

- камера приближается к месту клика, ввода или наведения за полсекунды до события и держится ещё 1,3 секунды;
- во время ввода текста зум сохраняется на всё время набора;
- события, идущие чаще чем раз в 1,6 секунды, объединяются в один план: камера не отъезжает, а сдвигается, причём только
  если следующее действие вышло из центральной зоны кадра;
- на время скролла и перехода между страницами камера возвращается к общему плану;
- приближенный кадр никогда не выходит за границы записи.

## GIF в пределах бюджета

GIF кодируется фильтрами палитры `ffmpeg`. Если файл больше бюджета, настройки понижаются по ступеням
(ширина 960 → 400, частота 15 → 8, цветов 256 → 48), пока файл не уложится. Если не уложился и на последней ступени —
команда завершается с кодом 1 и советом сократить ролик.

## 3D-пресеты

Пресет — готовая 3D-сцена с устройством и «слотами», куда встаёт ваше медиа.

```bash
node packages/cli/dist/bin.js studio presets list
```

```bash
node packages/cli/dist/bin.js studio presets preview laptop-orbit
```

```bash
node packages/cli/dist/bin.js studio render --repo examples/web-app --preset laptop-orbit --slot main=.repokit/capture/<запись>/video.mp4 --out docs/media/hero-3d.mp4 --gif
```

| Пресет | Слот `main` | Соотношения сторон вывода |
|---|---|---|
| `laptop-orbit` — ноутбук, камера облетает его | 16:10, изображение или видео | 16:9, 4:3, 1:1 |
| `phone-float` — парящий телефон | 9:19.5, изображение или видео | 16:9, 1:1, 4:5, 9:16 |
| `browser-tilt` — наклонённое окно браузера с параллаксом фона | 16:10, изображение или видео | 16:9, 4:3, 1:1 |

| Флаг | Значение |
|---|---|
| `--preset <имя>` | включает режим пресета вместо таймлайна |
| `--slot id=файл` | медиа для слота; путь относительно репозитория. Изображения: png, jpg, webp; видео: mp4, webm, mov |
| `--aspect 16:9` | соотношение сторон из поддерживаемых пресетом; по умолчанию первое |
| `--width <px>` | ширина кадра, по умолчанию 1280; высота считается из соотношения |
| `--gl angle\|swangle` | `angle` рисует на GPU (по умолчанию), `swangle` — программно, для машин без GPU и CI. Можно задать через `REPOKIT_GL` |

`studio still --preset … --frame N --out кадр.png` рендерит один кадр — удобно проверить, как встало медиа.

Правила проверки:

- слот без медиа, неизвестный слот, неподдерживаемый формат или соотношение сторон — ошибка (код 2);
- медиа не из `capture` — предупреждение «происхождение неизвестно», результат помечается так же, как любой другой;
- пропорции медиа отличаются от экрана больше чем на 3 % — предупреждение с указанием, что произойдёт: обрезка (`cover`) или поля (`contain`);
- видео короче пресета зацикливается, об этом тоже сообщается.

Содержимое экрана выводится без освещения и цветокоррекции: устройство вокруг — оформление, а картинка внутри остаётся такой,
какой её показало приложение. Устройства построены из простых фигур и не изображают конкретные продукты.

Как добавить свой пресет — в [CONTRIBUTING.md](../CONTRIBUTING.md).

## Режиссёрские сцены

Когда пресета мало: свои объекты, движение камеры к любой точке страницы, эффекты по кликам, карточки со значками и связи между ними,
видеоразбор устройства проекта (`studio explain`) — см. [scenes.md](scenes.md).

## Баннеры и слайды

Статичные картинки из фактов о проекте: название и тэглайн из полей автора, возможности — только подтверждённые кодом,
технологии — найденные в зависимостях, изображения — настоящие скриншоты из `capture`.

```bash
node packages/cli/dist/bin.js studio banner --repo examples/web-app --out docs/media/banner.png
```

```bash
node packages/cli/dist/bin.js studio deck init --repo examples/web-app
```

```bash
node packages/cli/dist/bin.js studio deck render --repo examples/web-app --deck examples/web-app/slides.deck.json --out-dir docs/slides --pdf
```

| Команда | Результат |
|---|---|
| `studio banner --out x.png [--size banner\|wide] [--theme dark]` | баннер проекта: `banner` — 1280×640, обложка репозитория на GitHub; `wide` — 1600×520, полоса для верха README (`readme plan --banner x.png`) |
| `studio deck init [--kind slides\|banner] [--theme light]` | описание слайдов `slides.deck.json`, собранное из фактов; его можно править |
| `studio deck render --deck f --out-dir docs/slides [--pdf]` | `slide-01.png`, … и, по флагу, `slides.pdf` |

Автоматически собираются слайды: титульный, проблема, решение, «что уже работает», скриншоты, технологии,
«что ещё не готово», команда, ссылки. Слайд без данных не создаётся, а пропуск попадает в список «для человека» —
текста за автора repokit не пишет. Слайд об ограничениях строится из утверждений-заглушек так же, как в README.

Описание слайдов — обычный JSON ([schemas/deck.schema.json](../schemas/deck.schema.json)) с макетами `title`, `split`,
`text`, `bullets`, `image`, `chips` и рамками `browser`, `phone`, `none`. Темы: `light`, `dark`, `glass`, `sunset`, `mint`, `mono`.

Плашки технологий — в фирменном цвете и с логотипом (значки из набора simple-icons, лицензия CC0). PDF содержит только картинки слайдов.

## Происхождение

Каждый результат записывается в `.repokit/media.manifest.json` с полем `derivedFrom` — хэшами исходных записей и таймлайна.
Если источник сцены не записан через `capture`, рендер выполнится, но выдаст предупреждение «происхождение неизвестно».

## Ограничения

- Рендер 14-секундного ролика 1280×720 занимает около двух минут на обычном ноутбуке.
- Между сценами нет переходов — только прямая склейка.
- Шрифт заголовка берётся системный, поэтому на разных ОС он может немного отличаться.
- Автоматического вырезания пауз нет: используйте `in`/`out` и `speed`.
- 3D-пресетов пока три, у каждого один слот; остальные три (дуэт телефона и ноутбука, изометрические карточки, терминал) запланированы на M8.
- В 3D-пресетах нет авто-зума и курсора: запись показывается как есть.
- 3D-рендер без GPU (`--gl swangle`) заметно медленнее.
