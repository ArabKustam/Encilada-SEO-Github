# readme — сборка README из фактов

Собирает README из того, что подтверждено: фактов `scan`, проверенных утверждений `claims.json`, матрицы `brief.json`,
медиа с известным происхождением и слов автора. Текста от себя не добавляет: чего нет — остаётся пустым местом
с пометкой и попадает в список «для человека». По умолчанию README пишется на русском.

## Команды

| Команда | Что делает |
|---|---|
| `readme presets` | список пресетов оформления |
| `readme human` | шаблон полей автора → `.repokit/readme.human.yaml` |
| `readme plan [--preset showcase] [--lang ru] [--hero docs/media/hero.gif] [--hero-dark …]` | черновик → `.repokit/readme.draft.md`, план по разделам, список «для человека» |
| `readme apply [--dry-run]` | записывает `README.md`; `--dry-run` показывает diff и ничего не меняет |
| `readme check` | проверяет текущий `README.md`; код 1 при проблемах |

Выбранные пресет, язык и медиа запоминаются в `.repokit/readme.options.json`.

## Пресеты

| Пресет | Для чего | Разделы |
|---|---|---|
| `compact` | короткий README без медиа-шапки | шапка, возможности, быстрый старт, демо, ограничения, лицензия |
| `showcase` | подача на хакатон | шапка по центру, главное изображение, проблема, решение, возможности, демо, архитектура (свёрнута), быстрый старт, для жюри, ограничения, команда, лицензия |
| `technical` | упор на устройство проекта | шапка, изображение, возможности, архитектура, таблица роутов (свёрнута), быстрый старт, для жюри, ограничения, лицензия |

Пресет — папка `presets/readme/<имя>/` с `preset.json` (название, обязательные разделы) и `template.md` (порядок разделов,
по одному `{{раздел}}` в строке, с опциями вроде `collapsible` и `variant=centered`). Заголовки и служебные фразы лежат
в `presets/readme/_i18n/ru.yaml` и `en.yaml`.

## Откуда берётся каждый раздел

| Раздел | Источник | Если данных нет |
|---|---|---|
| Шапка | название — поле `title` или имя проекта; тэглайн — поле `tagline`; бейджи — только проверяемые: лицензия из файла, CI при наличии workflow, основной язык | пометка «не заполнено» |
| Главное изображение | файл из `--hero`; `<picture>` при наличии тёмного варианта; alt — поле `heroAlt` или нейтральная фраза | пометка; файл не из `capture`/`studio` — предупреждение |
| Проблема, Решение | поля `problem`, `solution` | пометка |
| Возможности | утверждения `implemented` и `partial` с доказательством, прошедшим проверку; каждое со ссылкой на строки кода | пометка |
| Демо | поля `demoUrl`, `videoUrl` | раздел опускается |
| Архитектура | схема mermaid по импортам и обращениям к API в коде | раздел опускается |
| API и страницы | роуты из `scan` | раздел опускается |
| Быстрый старт | команды установки, запуска и тестов из `scan` | пометка |
| Для жюри | критерии и веса из `brief.json`, ссылки на утверждения и разделы | раздел опускается |
| Ограничения и планы | утверждения-заглушки и частичные, отсутствие тестов, поле `roadmap` | пометка |
| Команда | поле `team` | раздел опускается, пункт в списке «для человека» |
| Лицензия | файл лицензии, тип определяется по тексту | пометка: лицензию выбирает человек |

Обязательные для пресета разделы без данных получают пометку `<!-- FILL: … -->`; необязательные просто не выводятся.
Автор может исключить раздел полем `skip`.

## Правила честности

- Утверждение без доказательства, со статусом `unverified`, или чей код изменился после фиксации, в README не попадает.
  Об этом сообщается в предупреждениях и в списке «для человека».
- Заглушка (`mock`) выводится только в «Ограничениях».
- Если главное изображение смонтировано из записи с `demoData: true`, под ним ставится подпись «Демонстрационные данные».
- Бейджей со звёздами, скачиваниями и прочими непроверяемыми числами нет.
- Раздел «Для жюри» ссылается на другой раздел только если тот существует и заполнен.

## Существующий README

`apply` не затирает чужой текст молча:

- прежняя версия сохраняется в `.repokit/readme.backup.md`;
- ваши собственные разделы (заголовки второго уровня, которых нет среди генерируемых) переносятся без изменений и ставятся перед лицензией;
- заменяются только разделы, которые repokit собирает заново из тех же фактов: «Возможности»/Features и «Лицензия»/License;
- если ваш раздел похож на дубль «Быстрого старта» («Запуск», Usage, Installation…), он сохраняется, а в списке «для человека» появляется просьба оставить один вариант;
- текст до первого заголовка второго уровня заменяется шапкой.

Повторный `apply` без изменений в фактах ничего не меняет.

## readme check

Находит в `README.md`: незаполненные пометки `FILL`, ссылки и изображения, ведущие на несуществующие файлы репозитория,
изображения без alt-текста. Внешние ссылки не проверяются — это задача `verify` (веха M5).

## Особенность GitHub

Тег `<video>` в README работает только со ссылкой, которую GitHub выдаёт при перетаскивании файла в веб-редактор.
Поэтому главным медиа служит GIF или WebP, а ссылку на видео автор добавляет в поле `videoUrl` сам.
